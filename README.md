# B站点歌台

**让观众用弹幕点歌，在网易云音乐中排队播放。**

面向 B 站主播的桌面点歌工具：后台接收直播间点歌指令，主播在主界面管理歌单，通过独立小窗把当前歌曲和待播列表展示到直播画面中。支持自定义主题，可以换上自己的 OC、背景和配色。

## 主要功能

- **弹幕点歌**：按歌名、歌手搜索网易云歌曲，追加待播，不打断当前播放；房管可发送指令切歌。
- **真实歌单管理**：同步网易云当前曲目和播放状态，支持播放／暂停、下一首、排序、删除及清空列表。
- **接单控制**：随时暂停或恢复接单；支持歌曲黑名单，拦截不想播放的歌曲。
- **队列容量限制**：可设置最多接收多少首歌；启用后顺序播放，播完自动移出队列，满额拒绝新点歌。
- **直播歌单小窗**：适合 OBS、直播姬窗口捕捉，支持透明度、置顶、精简显示和定位当前歌曲。
- **主题工坊**：替换 PNG 人物与背景，调整配色、字体、文案和布局，实时预览主窗及小窗；可导入、导出完整主题包，也可复制提示词交给 AI 制作。

## 开始使用

运行环境：**Windows 10／11、WebView2 运行时、网易云音乐桌面客户端**。源码运行建议使用 Python 3.12。

### 启动

使用新版打包版时，运行 `bili-danmaku-song-order.exe`。源码运行：

```powershell
pip install -r requirements.txt
python main_gui.py
```

也可双击根目录唯一的测试启动脚本 `start_gui.bat`。

### 首次连接

1. 在点歌台内用 B 站 APP 扫码并确认登录，设置要接收弹幕的直播间房间号。
2. 手动退出正在运行的网易云音乐，包括托盘进程。
3. 点击顶栏的 **「网易云 · 未连接」**，以控制模式启动网易云，等待显示“已连接”。
4. 开始接单，观众发送点歌弹幕即可。

已在网易云 **3.1.3.203419** 上验证搜索、入队和播放控制；其他版本可能因客户端内部接口变化而不兼容。软件不会强制关闭网易云，也不会绕过账号的歌曲播放权限。

## 弹幕指令

```text
点歌 青花瓷
点歌 青花瓷 - 周杰伦
点歌 See You Again - Wiz Khalifa
```

歌手可省略；指定歌手时使用两侧带空格的半角 **` - `**，歌名和歌手本身可以含空格。

房管发送 **`下一首`** 可切歌。

在 **设置 → 点歌队列限制** 中开启容量限制，可设为 1–500 首，包含正在播放的歌曲。已有歌单超额时不会自动裁剪；暂停不会移除歌曲。此功能默认关闭。

## 展示歌单与制作主题

点击主界面 **「召唤小窗」**，在 OBS／直播姬中捕捉窗口 **「B站点歌台 · 直播歌单」**。小窗跟随主窗主题；窗口透明度是否被采纳取决于捕捉方式，请先检查直播预览。

打开 **主题 → 主题工坊**，可以基于玫瑰夜曲创建自己的主题。用户直接选择 PNG，程序自动处理素材；工坊顶部的 **「复制 AI 提示词」** 可直接发给 AI。

初始提供「黑睡莲·紫锋共振」「鹤望兰·暮光共鸣」两套可编辑预设。首次启动自动安装，可导出或删除；更新不覆盖修改，删除后不自动恢复。Haruka 不再自动安装，玫瑰夜曲仅作为工坊制作模板；已有安装副本不删除。

分享和导入统一使用 **`.songtheme` 文件**，其中包含配置及图片。对方通过 **主题工坊 → 导入主题包 → 保存并应用** 即可使用，无需另发素材。

工坊左侧 **在线主题库** 可从本仓库单独下载主题，不用更新整个EXE；刷新后选择下载，安装不会自动应用。已安装同ID主题下载为副本，不覆盖用户修改。程序只在首次获得该功能时需升级一次，之后新增主题无需升级程序。发布者流程见[在线主题库说明](docs/themes/ONLINE.md)。

## 程序内更新

打开 **设置 → 版本与更新** 可检查 GitHub 正式发布版本。界面启动5秒后首次后台检查，此后每4小时检查；发现新版时设置按钮显示升级角标，不自动安装或重启。

便携EXE版可下载完整更新包，验证 Ed25519 发布签名和 SHA256 后点击“退出并更新”。更新助手等待程序退出，只替换主程序和许可文件；新版界面启动确认后保留一份上一版备份，可在设置回退。更新期间请先保存主题工坊修改；不会关闭网易云，不覆盖配置、黑名单或用户主题。中断更新可使用设置中的恢复入口；若程序无法启动，保留 `.update/` 中事务及旧版文件，按[更新说明](docs/updating.md)手动恢复。

源码通过 `start_gui.bat` 启动也会检查真实版本，但不会自动修改Git工作区，请手动下载Release或更新源码。首次公开版还没有更高版本时会显示已是最新版或暂无正式更新。

## 注意事项

- 登录凭证保存在本地 `config.json`，不要随程序、日志或截图分享。登录失效后可能需要重新扫码。
- 黑名单保存在 `song_blacklist.txt`，可在设置里编辑。打包版的配置和黑名单都在 EXE 旁边，请放在可写目录；更新时只替换 EXE，保留这些数据文件。旧版中文黑名单会自动迁移，发布包不包含个人黑名单。
- 新用户首次生成黑名单时默认加入「义勇军进行曲」「威风堂堂」。可在设置中移除；已有黑名单（包括手动清空的文件）不覆盖、不重复添加。
- 删除、清空和消费队列操作会修改网易云真实待播列表，但不删除收藏或本地歌曲。
- 网易云控制通道仅供本机使用，请勿将 `127.0.0.1:9223` 暴露到外网。
- 请自行确认音乐播放及主题素材的使用授权。

开发、测试、目录结构与打包命令见 [开发文档](docs/development.md)。原版落雪控制台入口 `main.py` 仍保留，与上述网易云 GUI 分开使用。
